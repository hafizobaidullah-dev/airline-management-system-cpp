# Airline Management System (C++)

## 📌 Description
A console-based Airline Management System developed in C++ that allows management of flights, passengers, and bookings using Object-Oriented Programming principles.

---

## ✈️ Features
- Add, view, and manage flights
- Passenger registration system
- Ticket booking and cancellation
- Search available flights
- Store data using file handling

---

## 🛠️ Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- Data Structures (basic)

---

## 🎯 Purpose
This project was developed to strengthen understanding of OOP concepts, file handling, and real-world system design in C++.

---

## 📂 How to Run
1. Compile using any C++ compiler (g++)
2. Run main.cpp
3. Follow console instructions
